🎯 C'est quoi Pupitre ?

Pupitre est une application web collaborative faite pour les musiciens qui jonglent entre plusieurs projets. Chacun y retrouve ses groupes, ses morceaux, ses maquettes, ses répètes et ses concerts — sans jamais mélanger les projets.

🎼

Un espace par groupe

Répertoire, événements, tâches, membres, contacts : tout est cloisonné. Chaque musicien ne voit que les groupes où il joue, et leurs membres.

🔄

Tout est synchronisé

Ce que l'un écrit, les autres le voient en quelques secondes. Plus de « je te renvoie la setlist par mail ».

🎧

Maquettes intégrées

Upload direct des fichiers audio depuis l'appli. Écoute en un clic depuis n'importe quel appareil.

🎤

Pensée pour la scène

Mode plein écran avec paroles, accords, structure, métronome et défilement automatique.

💡 En un mot

C'est le classeur du groupe, la setlist du concert, le carnet d'idées, le calendrier des répètes et le carnet d'adresses du groupe — réunis dans une seule page qui tient dans la poche.

🚀 Premiers pas

1

Reçois ton code personnel

Un admin te transmet ton code personnel (8 caractères, type K7M2-9XQP) par message ou QR code. Ce code t'est propre : garde-le quelque part (note, SMS à toi-même, gestionnaire de mots de passe), il te permettra de te reconnecter sur un autre appareil.

2

Entre ton code

Ouvre Pupitre, tape ton code dans le champ Code et clique sur Entrer. Les majuscules et les tirets sont facultatifs. Tu arrives directement dans ton espace.

3

Vérifie la synchro

Dans le menu, la pastille à côté de ☁️ Synchro doit afficher ● à jour. Si elle dit ○ hors ligne, clique dessus et vérifie que l'URL Firebase et le code de groupe sont bien remplis (ils te sont donnés par un admin).

4

Installe-la sur ton écran d'accueil

Pour qu'elle s'ouvre comme une vraie appli, plein écran :
• iPad/iPhone → Partager → « Sur l'écran d'accueil »
• Android → menu ⋮ → « Ajouter à l'écran d'accueil »
• PC → icône d'installation dans la barre d'adresse.

✅ Ton code est réutilisable

Une fois que tu as ton code, tu peux t'en servir sur plusieurs appareils — ton téléphone, ta tablette, ton ordinateur. Si un jour tu es déconnecté (nouvel appareil, cache vidé…), retape simplement le même code. Tu peux aussi en générer un nouveau à tout moment via le bouton 🔑 Code (voir plus bas).

🔗 Lier ton compte Google (ordinateur)

Sur un ordinateur, tu peux lier ton compte Google via le bouton 🔗 Google en bas du menu : ça te permet de te reconnecter en un clic. Sur iPhone/iPad, ce bouton ne fonctionne pas — c'est une limitation d'iOS. Dans ce cas, ton code personnel reste ta solution principale.

🔒 Tu ne vois que tes groupes

Dans Pupitre, chacun ne voit que les groupes où il joue et les musiciens de ces groupes. Les autres projets restent invisibles. Un groupe manque ? Demande à un admin de t'y ajouter.

Ton menu utilisateur (en bas du menu)

Tout en bas du menu de gauche, tu trouves ta carte personnelle : ton avatar, ton nom, tes instruments, et trois boutons pour gérer ton compte.

🎨
Avatar Clique sur ton avatar pour changer ta couleur. Elle apparaît partout dans l'appli : commentaires, disponibilités, journal de répète.
🔑
🔑 Code — changer mon code personnel Génère un nouveau code à 8 caractères. L'ancien est immédiatement supprimé — pratique si tu penses qu'il a fuité, ou si tu veux repartir sur un code propre. Note le nouveau quelque part de sûr avant de fermer la fenêtre.
🔗
🔗 Google — lier mon compte Google Disponible uniquement sur ordinateur (limitation iOS sur iPhone/iPad). Une fois lié, « Se reconnecter avec Google » te ramène dans ton espace sur n'importe quel appareil, sans code.
⎋
⎋ Quitter — me déconnecter Te déconnecte de cet appareil. Si tu n'as pas lié ton compte Google, tu auras besoin de ton code (ou d'un nouveau code généré par un admin) pour revenir.

🧭 Les 6 espaces de l'appli

Le menu de gauche (ou le ☰ sur mobile) contient plusieurs entrées. Cinq sont accessibles à tous, la sixième (Musiciens) est réservée à l'admin.

🏠
Aujourd'hui Ton tableau de bord personnel : prochains événements, tâches à faire, morceaux en cours, et la carte « À réviser avant la répète ». Tous tes groupes confondus, avec un filtre en haut pour isoler un groupe.
🎼
Mes groupes La liste de tes groupes, c'est la page d'accueil. Clique sur l'un d'eux pour entrer dans son espace : membres, répertoire, tâches, événements, journal, stats, contacts, notes privées.
📅
Calendrier Vue mensuelle de tous tes événements. Repère les conflits d'agenda (un même musicien attendu à deux endroits). Navigation par mois avec ← →, ou retour direct à aujourd'hui.
🎤
Concerts Le tableau de bord de toutes tes dates : setlists, dispos, fiche technique, cachet et répartition (administrateur seul). Les repères en haut indiquent ce qui reste à préparer pour chaque concert.
🔍
Recherche Tape un mot et retrouve-le partout : titres, paroles, accords, structure, notes, journal de répète, commentaires, lieux… Insensible aux accents et à la casse.
🧑‍🎤
Musiciens (admin) Visible uniquement par l'administrateur. Invitation de chaque musicien par code ou QR code, suivi de ceux qui sont déjà connectés, retrait d'un accès, modification d'une fiche (nom, initiales, couleur), rattachement à d'autres groupes.

🧑‍🎤 Gérer les musiciens

Tout ce qui touche aux personnes se trouve à deux endroits : la page 🧑‍🎤 Musiciens (vue d'ensemble, réservée à l'admin) et l'onglet Membres d'un groupe (fiche détaillée par groupe).

Ajouter un musicien à un groupe

1

Ouvre le groupe concerné

Par exemple « Bipolaire ».

2

Onglet Membres

En haut à droite, tu as deux choix :
• + Ajouter un musicien existant… — pour rattacher quelqu'un qui existe déjà dans un autre groupe.
• + Nouveau musicien — pour créer une fiche toute neuve.

3

Puis Inviter

Une fois le musicien ajouté à un groupe, un bouton Inviter apparaît sur sa fiche dans l'onglet Membres (et sur la page 🧑‍🎤 Musiciens). Clique dessus pour générer son code personnel.

💡 Lien d'invitation magique

Le message d'invitation contient un lien cliquable en plus du code à 8 caractères. Si ton musicien l'ouvre depuis son téléphone, tout est automatique : il n'a pas besoin de taper le code. S'il préfère, il peut aussi ouvrir l'appli et taper le code à la main — les deux méthodes fonctionnent.

Ajouter un musicien à plusieurs groupes en un clic

Depuis la page 🧑‍🎤 Musiciens, sur la fiche de n'importe quel musicien, un menu déroulant + Groupe… liste les groupes où il n'est pas encore. Choisis-en un, il est ajouté immédiatement. Retire-le d'un groupe avec le ✕ à côté du nom du groupe, dans la liste de ses badges.

Modifier un musicien (nom, initiales, couleur…)

Sur la page 🧑‍🎤 Musiciens ou dans l'onglet Membres d'un groupe, clique sur ✎ Modifier :

  • Prénom / nom — corrige une faute de frappe, ça s'applique partout.
  • Initiales — les 2 lettres de l'avatar.
  • Instruments par défaut — la liste qui apparaît sous son nom si aucun instrument n'est précisé pour un groupe.
  • Couleur — celle de l'avatar dans toute l'appli.

Instruments différents selon le groupe

Un musicien qui joue de la basse dans un groupe et du synthé dans un autre doit pouvoir avoir deux fiches distinctes. C'est possible :

1

Ouvre le groupe concerné

Par exemple « Bipolaire ».

2

Onglet Membres

Trouve la fiche du musicien, bouton Instrument.

3

Écris son rôle pour ce groupe

Par exemple « Basse, chœurs ». Laisse vide pour utiliser son instrument par défaut.

✅ Logique d'affichage

Partout dans l'appli : si un instrument est défini pour ce groupe, c'est celui-ci qui s'affiche. Sinon, c'est l'instrument par défaut du musicien (celui saisi à sa création).

Droits : admin ou membre

  • Admin — peut modifier le groupe, inviter, créer, modifier et supprimer n'importe quel morceau, événement, tâche. Peut aussi voir et saisir les finances d'un concert, gérer les contacts et lancer le nettoyage des médias.
  • Membre — peut voir, commenter, cocher ses disponibilités, éditer les morceaux, ses propres parties et notes. Ne peut pas supprimer d'élément du groupe.

Le bouton Passer admin / Rendre membre de la fiche membre bascule l'un vers l'autre. Il faut toujours au moins un admin par groupe : l'appli refuse de retirer le dernier.

Supprimer un musicien

Le bouton Supprimer retire définitivement le musicien : de tous les groupes, des tâches, des disponibilités et des notes privées. Impossible s'il est le seul admin d'un groupe — commence par passer un autre membre admin.

⚠ Ne pas confondre avec « Retirer l'accès »

Retirer l'accès (page Musiciens) ne supprime pas le musicien : ça retire sa session sur un appareil. Il est toujours dans tes groupes, ses données sont intactes, il pourra être réinvité plus tard.

🎵 Les morceaux

Chaque groupe a son répertoire. Les morceaux sont affichés soit en pipeline (colonnes par statut : Idée → Écriture → Maquette → Arrangement → Répétition → Prêt scène → En concert → Archivé), soit en liste. Le bouton en haut à droite bascule entre les deux, plus une vue 🎧 Son.

🎯

Fiche d'un morceau

La tonalité et le BPM apparaissent sous le titre. En dessous : Structure, Accords, Paroles, Notes de travail. Tout est éditable à tout moment.

🎸

Parties par instrument

Chaque membre peut écrire ses propres notes pour un morceau (riff en drop D, capo 2, entrée au 2e couplet…). Visibles par tous les membres du groupe.

📼

Versions

Chaque morceau garde son historique de maquettes : v1, v2, « maquette téléphone »… Avec un lecteur intégré pour écouter directement.

📋

Copier vers…

Un morceau qui pourrait marcher dans un autre groupe ? Le bouton « Copier vers… » le duplique dans les groupes de ton choix, sans toucher à l'original.

💡 Tri alphabétique

Dans toutes les vues (Pipeline, Liste, dropdowns, Copier vers…), les morceaux apparaissent par ordre alphabétique. Les accents sont ignorés (« Écume » se place à côté de « Ecume »).

🎧 Les maquettes audio (vue Son)

La vue 🎧 Son rassemble tous les enregistrements d'un groupe. C'est l'endroit idéal pour écouter les idées en travaillant.

Comment ça marche

  • Elle affiche uniquement les morceaux qui ont au moins un fichier audio.
  • Chaque morceau apparaît dans une carte avec toutes ses versions, la plus récente en premier.
  • Clique sur ▶ Écouter pour lancer une version : le lecteur apparaît en bas.
  • Le lecteur continue même si tu changes de page dans l'appli.
  • Clique sur ✕ pour fermer le lecteur.

Ajouter une maquette à un morceau

1

Ouvre le morceau → Versions

Tu vois la liste des versions existantes, ou « Aucune version ».

2

Clique + Version

Un formulaire s'ouvre : label, notes, fichier audio.

3

Choisis ton fichier

Clique sur « Choisir un fichier » et sélectionne ton M4A, MP3, MP4… L'envoi démarre tout seul à la validation.

4

Clique Créer

Le bouton affiche Envoi… pendant quelques secondes selon la taille. Puis la version apparaît avec son bouton ▶.

💾 Où vont mes fichiers ?

Ils sont stockés sur un service cloud sécurisé. Seuls les membres de ton groupe peuvent y accéder. Les fichiers restent disponibles même après la fermeture de l'appli.

📏 Taille des fichiers

Reste sous 50 Mo par fichier (limite de l'appli). Un MP3 de 5 minutes en qualité standard fait environ 5 Mo — c'est largement suffisant. Évite les WAV non compressés, qui pèsent dix fois plus lourd.

Modifier ou supprimer une version

Sur la fiche du morceau, dans la section Versions :

  • ✎ pour modifier (label, notes, remplacer le fichier)
  • ✕ pour supprimer la version. Le fichier audio est retiré du serveur dans la foulée. Réservé à l'admin.
  • ▶ Écouter pour lancer la lecture

📅 Les événements

Un événement, c'est une répète, un concert, une session studio, ou tout autre rendez-vous que tu inventes. Chaque groupe a sa liste, avec les événements à venir en premier.

🎸
Type d'événement Répétition, Concert, Studio, Autre — et tu peux en créer d'autres (Résidence, Interview, Balance…) avec le bouton ＋.
✅
Disponibilités Chaque membre indique Oui / Peut-être / Non. Un résumé s'affiche en haut : « 3 oui, 1 peut-être, Marco sans réponse ».
⚠️
Conflits d'agenda Si un même musicien est attendu à deux endroits au même moment, l'appli t'avertit automatiquement.
🔁
Répétitions récurrentes Un formulaire qui crée d'un coup toutes les répètes hebdo (ou bi-mensuelles) sur 3 mois.
🗑️
Suppression réservée à l'admin Seul l'administrateur du groupe peut supprimer un événement. Un membre peut tout créer et tout modifier, mais pas effacer.

🎧 À réviser avant la répète

Sur l'écran « Aujourd'hui », dès qu'une répétition est prévue dans les 14 prochains jours avec des morceaux à travailler en priorité, une carte apparaît en haut : la date, les notes de la répète et la liste des morceaux, avec tonalité, BPM et tes tâches liées.

Touche ▶ Écouter pour lancer l'enregistrement le plus récent, et coche la case quand tu l'as travaillé. Sur la page de la répétition, chaque morceau indique combien de musiciens l'ont révisé.

📄 Envoyer la setlist en PDF

Sur la page d'un événement, le bouton 📄 PDF crée une feuille A4 propre avec le groupe, la date, le lieu, les morceaux numérotés, tonalité, BPM et durée totale. Choisis le grand format (lisible sur scène, à imprimer) ou le compact (plus de morceaux par page).

Sur téléphone et tablette, le menu de partage s'ouvre tout seul : message, WhatsApp, e-mail, AirDrop, impression. Le PDF se crée sur l'appareil, sans connexion internet.

📅 Export vers l'agenda (avec rappels)

Chaque événement peut être envoyé vers ton agenda personnel : Google Calendar, Apple Calendrier, Outlook. Une fois l'événement ajouté, ton téléphone te prévient tout seul — même si Pupitre est fermé.

Comment faire

1

Ouvre un événement

Depuis le calendrier, un groupe, ou le dashboard.

2

Clique sur 📅 Agenda

En haut à droite de la page.

3

Choisis ton mode d'export

• Sur téléphone / tablette : 📤 Partager → le menu natif s'ouvre (message, WhatsApp, mail, AirDrop, impression) → tu choisis ton agenda.
• Sur ordinateur : 📅 Télécharger → le fichier .ics arrive dans tes téléchargements, tu l'ouvres d'un double-clic.

4

L'événement s'ajoute avec 2 rappels

Par défaut : la veille et 2 heures avant. Tu peux modifier ces rappels dans ton agenda si tu préfères d'autres horaires.

✅ Ton téléphone sonne tout seul

Une fois ajouté à ton agenda, l'événement reste dans ton calendrier natif et déclenche ses rappels même si tu n'ouvres pas Pupitre, même hors ligne.

💡 Mise à jour automatique

Si la date d'un événement change dans Pupitre, ré-exporte-le : l'agenda met à jour l'événement existant au lieu de créer un doublon.

🎤 Le tableau de bord des concerts

L'entrée 🎤 Concerts du menu rassemble toutes les dates de tes groupes, avec ce qui reste à préparer pour chacune.

En un coup d'œil

Pour chaque concert : la setlist et sa durée, les réponses de disponibilité, la fiche technique, les points à faire, et le compte à rebours. Les repères en haut indiquent le nombre de concerts à venir, ceux qui n'ont pas de setlist et les réponses manquantes.

Cachet et répartition (administrateur seul)

Sur la page d'un concert, l'administrateur saisit le cachet, les frais (essence, location…) et une éventuelle mise en caisse pour le groupe. L'appli calcule le net et la part de chacun. La case à gauche indique qui a joué, « part » permet une demi-part, et la case « payé » suit les reversements.

Ces montants sont stockés à part et ne sont lisibles que par l'administrateur : les autres musiciens ne les voient pas. Un export CSV est disponible pour la comptabilité.

✅ Les tâches

Chaque groupe a sa liste de tâches, pour ne plus oublier « écrire le 2e couplet » ou « confirmer le cachet ».

  • Plusieurs responsables par tâche — tu peux cocher Jacques et Marco.
  • Échéance — les tâches en retard passent en rouge, celles du jour en orange.
  • Lien vers un morceau — la tâche apparaît alors directement sur la fiche du morceau.
  • Modification — le crayon ✎ ouvre la fiche sans supprimer.
  • Suppression réservée à l'admin — les membres peuvent créer et modifier, mais pas effacer.

📖 Le journal de répète

Après chaque répète, chacun peut noter ce qui s'est passé — en trois questions simples.

✓ Ce qui a marché

« Intro plus fluide », « refrain validé », « bon son sur Horizon »…

✎ À revoir

« Le pont de Marée basse », « transitions du set »…

→ Prochaine fois

« Tester une nouvelle intro », « enregistrer les maquettes »…

📚

Onglet Journal

Dans un groupe, l'onglet Journal regroupe toutes les notes par date. Parfait à relire 5 minutes avant la répète suivante.

🎤 Le mode scène

C'est le mode plein écran, pensé pour le concert ou la répète. Il s'ouvre depuis la fiche d'un événement, via le bouton 🎤 Mode scène.

📱
Plein écran Plus de barre d'adresse, plus de menu. Juste le morceau en cours.
👉
Navigation au swipe Glisse le doigt vers la gauche ou la droite pour passer au morceau suivant ou précédent. Sur ordinateur : flèches ← →.
🔍
Taille ajustable Les boutons A− / A+ changent la taille du texte. Pratique si l'iPad est posé au sol ou accroché au pied de micro.
🥁
Métronome Un clic régulier au BPM du morceau, avec le temps 1 accentué. Ajustable en direct par pas de 2. Se cale automatiquement sur chaque morceau.
📜
Défilement automatique Le texte descend tout seul pendant que tu joues. Deux mains libres. Ajustable avec − / + pour aller plus ou moins vite. Ta vitesse préférée est mémorisée. Le défilement s'arrête automatiquement en bas de page.
🎯
Ta partie mise en avant Si tu as écrit des notes pour ton instrument, elles apparaissent en haut du morceau. Tes notes privées sont aussi affichées, en bleu.
✅ L'écran ne s'éteint pas

Tant que tu es en mode scène, l'appareil reste allumé. Pas de mauvaise surprise au milieu du 2e morceau.

💡 Vitesse de défilement — repères

• Paroles denses (beaucoup de texte) : 15-25
• Chanson normale (paroles + accords) : 30-40
• Contenu aéré : 50-70
• Solo instrumental long : 80-120
Teste ta vitesse en répète et garde-la. Chaque appareil mémorise la sienne.

🎛️ La fiche technique

Directement sur la page d'un événement, une section pour préparer le concert avec le régisseur son.

🎚️
Patch list Tableau des voies : numéro, source (basse, chant, kick…), micro/DI, remarque. Tu peux tout modifier, supprimer, ajouter : les voies se classent automatiquement par numéro.
🎨
Plan de scène Texte libre pour décrire qui se place où — plus une image que tu peux changer ou retirer.
🎒
Matériel à apporter Checklist avec un responsable par ligne. Chacun coche ce qu'il apporte.
📋
Texte pour la salle Un bouton qui génère toute la fiche en texte brut, prêt à coller dans un mail au régisseur.

📇 Contacts & booking

Chaque groupe a son propre carnet d'adresses : salles, régisseurs, studios, journalistes, webzines… Tout ce qui n'est pas un musicien mais que tu veux garder sous la main.

Ajouter un contact

1

Ouvre un groupe → onglet Contacts

Nouvel onglet à côté de Journal, Stats et Notes privées.

2

Bouton + Contact

En haut à droite.

3

Remplis la fiche

Nom, type (salle, régisseur, studio, presse, autre), téléphone, email, adresse, site web, notes libres.

Utiliser un contact

  • 📞 Clique sur le numéro → ton téléphone lance l'appel (ou ton ordinateur ouvre l'appli Téléphone).
  • ✉️ Clique sur l'email → ton client mail s'ouvre avec l'adresse pré-remplie.
  • 🌐 Clique sur le site web → l'adresse s'ouvre dans un nouvel onglet.
  • 📍 L'adresse est affichée pour la retrouver facilement.
  • 📝 Les notes te rappellent les détails (« contact rencontré au festival, connaît bien Marco… »).

Modifier ou supprimer

Sur chaque fiche : ✎ pour modifier, ✕ pour supprimer. Réservé à l'admin pour la suppression.

✅ Pourquoi c'est utile

Avant un concert, tu ouvres la fiche de la salle : l'adresse, le nom du régisseur, son portable. Tu appelles en un clic. Plus besoin de fouiller dans tes mails ou tes SMS.

🧹 Nettoyer les médias

Au fil du temps, il peut rester sur le serveur des fichiers audio ou des images qui ne sont plus rattachés à rien (par exemple une maquette qu'on a supprimée quand on était hors ligne). Cette fonction les détecte et propose de les supprimer.

1

Menu → 🧹 Nettoyer les médias

Section Sauvegarde du menu de gauche. Réservé à l'administrateur.

2

L'appli scanne

Elle compare ce qui est sur le serveur avec ce qui est référencé dans l'appli. Ça prend quelques secondes.

3

Elle te montre le résultat

• « Rien à nettoyer » → tout va bien, tu peux fermer.
• X fichier(s) orphelin(s) → tu peux voir la liste avant de valider.

4

Tu confirmes

Seuls les fichiers abandonnés sont supprimés. Rien d'actif n'est touché.

💡 À faire de temps en temps

Une fois par trimestre suffit. C'est utile si vous uploadez beaucoup de maquettes ou de plans de scène. Les fichiers nettoyés libèrent de l'espace sur le serveur — ce qui garde l'appli gratuite.

🔍 La recherche

Une seule barre, tous les résultats. Tape 2 lettres minimum, l'appli cherche en direct dans :

  • Titres, tonalités, structures, accords, paroles, notes des morceaux
  • Notes que chaque musicien a écrites pour son instrument
  • Lieux, notes et journal de répète des événements
  • Titres de tâches
  • Commentaires (sur morceaux et événements)

Seuls les contenus de tes groupes sont cherchés. Les résultats sont groupés par type, avec un extrait où le mot recherché est surligné. Un clic t'ouvre directement le morceau, l'événement ou la tâche.

💡 Astuce

Cherche drop D, pont, La Cave, maquette… n'importe quel mot qui te trotte dans la tête. La recherche ignore les accents et la casse.

✨ Astuces & bonnes pratiques

🎨

Chacun sa couleur

Clique sur ton avatar en bas à gauche du menu. Ta couleur apparaît partout : commentaires, disponibilités, journal.

🔒

Notes privées

Sur la page d'un morceau et dans l'onglet d'un groupe, tu as des notes visibles uniquement par toi. Elles restent sur ton appareil et ne sont pas synchronisées.

🔑

Garde ton code précieusement

Ton code personnel est ta clé pour revenir sur l'appli si tu es déconnecté. Note-le dans un endroit sûr. Tu peux aussi en régénérer un à tout moment via le bouton 🔑 Code.

📅

Exporte tes concerts dans l'agenda

Le bouton 📅 Agenda envoie l'événement dans ton calendrier avec deux rappels automatiques. Fini les oublis.

⬇️

Sauvegarde de temps en temps

Le bouton Exporter ouvre une fenêtre avec deux options : « Partager » (enregistrer dans Fichiers, envoyer par mail…) ou « Copier tout ». Une fois par mois, tu es tranquille.

🌐

Fonctionne hors-ligne

Les données locales restent lisibles même sans réseau. Dès que la connexion revient, tout se synchronise.

⚡

Synchro automatique

Pas de bouton « sauvegarder ». Chaque modification part au serveur en moins d'une seconde.

👥

Rôle admin

Un admin peut modifier un groupe, gérer les membres, changer les rôles, supprimer, gérer les finances et les contacts. Les membres normaux peuvent tout créer et modifier, mais pas supprimer.

🎵

Tri alphabétique partout

Les morceaux apparaissent toujours dans l'ordre alphabétique, avec accents et casse ignorés, dans toutes les vues et tous les dropdowns.

🧹

Nettoyage trimestriel

Une fois de temps en temps, lance Nettoyer les médias dans le menu. Ça libère de l'espace sur le serveur et garde l'appli gratuite.

❓ Questions fréquentes

Je ne vois pas ce que les autres ont écrit

Vérifie que la synchro est bien configurée : en bas du menu, la pastille doit afficher ● à jour. Si c'est ○ hors ligne, clique sur ☁️ Synchro et vérifie l'URL Firebase + le code de groupe.

J'ai perdu mon code

Demande à un admin de t'en générer un nouveau : page 🧑‍🎤 Musiciens ou onglet Membres d'un groupe → bouton Inviter sur ta fiche. Il te transmettra le code.

Je ne vois pas un groupe, ou un musicien

C'est voulu : chacun ne voit que les groupes dont il est membre, et seulement les musiciens de ces groupes. Demande à un admin de t'ajouter au groupe manquant.

Comment changer mon instrument selon les groupes ?

Sur la page d'un groupe, onglet Membres, un admin peut préciser ton instrument spécifique à ce groupe (bouton Instrument sur ta carte). L'instrument par défaut (modifiable via ✎ Modifier) reste utilisé pour les autres groupes.

Comment recevoir des rappels la veille d'un concert ?

Ouvre la page du concert → bouton 📅 Agenda. Une fois l'événement ajouté à ton calendrier, ton téléphone te prévient automatiquement la veille et 2 heures avant. Ça marche même si Pupitre est fermé.

Pourquoi je ne peux pas supprimer un événement ?

La suppression est réservée à l'administrateur du groupe. Si tu es membre, tu peux créer et modifier, mais pas effacer. Demande à ton admin si tu penses qu'un élément doit disparaître.

Puis-je utiliser l'appli sur plusieurs appareils ?

Oui. Chaque appareil garde sa propre session. Le plus simple : tape ton code personnel sur chaque appareil. Tes notes privées, elles, restent sur l'appareil où tu les as écrites.

Que se passe-t-il si je supprime un morceau ?

Le morceau disparaît du répertoire, ainsi que ses versions et ses tâches liées. Il est aussi retiré des setlists où il apparaissait. Action définitive : une confirmation est demandée avant. Réservé à l'admin.

Que se passe-t-il si je supprime une version audio ?

La version disparaît et le fichier audio est retiré du serveur. Action immédiate et définitive. Réservé à l'admin.

Le métronome ne fait pas de son

Vérifie le volume de l'appareil. Sur iPad/iPhone, le premier clic sur 🥁 débloque l'audio. Si le son reste muet, ferme et rouvre le mode scène.

Le défilement automatique ne démarre pas

Si le contenu du morceau tient entièrement à l'écran, il n'y a rien à faire défiler. Ajoute des paroles ou agrandis la police (A+) pour que le texte dépasse l'écran, puis relance 📜.

Mes images de plan de scène ne s'affichent pas chez les autres

Vérifie que la synchro est active. La première fois, une image peut mettre quelques secondes à arriver. Si le problème persiste, utilise « Changer » pour renvoyer l'image.

Comment changer mon code personnel ?

En bas du menu, clique sur 🔑 Code. Un nouveau code aléatoire est généré, l'ancien est supprimé immédiatement. Note le nouveau quelque part de sûr avant de fermer la fenêtre — sinon tu devras demander à un admin de t'en régénérer un.

Mon nom est coupé en bas du menu

Depuis la dernière version, ton nom est affiché sur sa propre ligne et les trois boutons (🔑 Code / 🔗 Google / ⎋ Quitter) sont en dessous, tous cliquables, quelle que soit la taille de l'écran. Si tu vois encore l'ancienne disposition, recharge l'appli : ferme-la et rouvre-la, ou clique sur le bandeau « Nouvelle version disponible ».
